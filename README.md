# ФинГород — Образовательная платформа финансовой грамотности

Образовательная платформа с элементами геймификации для формирования финансовой грамотности у обучающихся начальной школы (7–10 лет).

Разработано в рамках выпускной квалификационной работы.

## Технологический стек

- **Frontend**: React 18.2 + TypeScript 5.3 + Phaser.js 3.80 + Redux Toolkit 2.0 + Vite 5.0
- **Backend**: Node.js 20 LTS + NestJS 10.0 + TypeScript 5.3 + TypeORM 0.3
- **БД**: PostgreSQL 16
- **Real-time**: Socket.io 4.6
- **Тестирование**: Jest 29.7, k6 (нагрузочное)
- **Инфраструктура**: Docker, Docker Compose, Nginx

Обоснование выбора стека приведено в разделе 1.3 ВКР.

## Быстрый запуск

### Через Docker (рекомендуется)

```bash
git clone <url>
cd fin-gorod-platform
cp .env.example .env
docker-compose up -d
```

После запуска:
- Клиент: http://localhost:5173
- API: http://localhost:3000
- Swagger: http://localhost:3000/api/docs

### Локально (для разработки)

```bash
# Установка зависимостей
npm install

# Поднимаем PostgreSQL
docker-compose up -d postgres

# Миграции
cd apps/server
npm run migration:run

# Запуск сервера
npm run start:dev

# В другом терминале — клиент
cd apps/client
npm install
npm run dev
```

## Тесты

```bash
# Все unit + integration тесты
cd apps/server
npm test

# С покрытием
npm run test:cov

# E2E
npm run test:e2e
```

Покрытие тестами серверной части: ~78% (раздел 3.2 ВКР).

Тесты покрывают:
- Расчёт вознаграждения ФинКоинов (формула R с golden-бонусом 15%)
- ACID-транзакции начисления/списания
- Каскадное удаление по 152-ФЗ
- Проверку условий 18 достижений
- Алгоритм адаптивной сложности (скользящее среднее N=10)
- RBAC (4 роли)

## Соответствие нормативным требованиям

| Требование | Реализация |
|---|---|
| 152-ФЗ (локализация ПДн) | Развёртывание на серверах РФ, каскадное удаление при отзыве согласия |
| 152-ФЗ (шифрование) | TLS 1.3 (Nginx + Let's Encrypt) |
| 436-ФЗ (защита детей) | Маркировка 6+, фильтр стоп-слов (2400+ записей), отключены личные сообщения |
| ГОСТ Р 52872-2019 | WCAG AA, контраст 5.2:1, ARIA-атрибуты, клавиатурная навигация |

## Модули геймификации (раздел 2.3 ВКР)

- **«ФинГород»** — 6 районов по тематическим категориям (Tiled tilemap)
- **ФинКоины** — виртуальная валюта с дифференцированным начислением
- **18 достижений** — 3 уровня прогрессивной разблокировки
- **Адаптивная сложность** — 5 уровней, автоподстройка по скользящему среднему
- **Золотой бонус** — 15% вероятность удвоения награды (теория Скиннера)
